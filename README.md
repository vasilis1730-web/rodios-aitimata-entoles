# ΡΟΔΙΟΣ — Αιτήματα και Εντολές Εργασίας

Νέα, ανεξάρτητη εξέλιξη των δύο εφαρμογών, χωρίς μεταβολή του υφιστάμενου repository ή του υφιστάμενου Supabase.

## Εφαρμογές

- `/aitimata/`: εφαρμογή κινητού για αιτήματα πολιτών.
- `/entoles/`: εφαρμογή προσωπικού για αιτήματα, εντολές εργασίας, οικονομικά και παραλαβές.

Και οι δύο εφαρμογές χρησιμοποιούν μόνο τη νέα σύνδεση που δηλώνεται στο `config.js`.

## Προετοιμασμένες βασικές εγγυήσεις

- Καθαρή βάση χωρίς παλιά αιτήματα, εντολές, πληρωμές ή πρωτόκολλα.
- Ατομική αρίθμηση με τον μικρότερο διαθέσιμο αριθμό, χωρίς κενά μετά από διαγραφή.
- Οριστική διαγραφή μόνο από Administrator, με cascade και καθαρισμό Storage.
- Επαναφορά συνδεδεμένου αιτήματος σε `Προς ενέργεια` μετά από διαγραφή εντολής.
- Πρωτόκολλο αποθηκεύεται μόνο με ακριβώς 3 διαφορετικές υπογραφές και αντιστοίχιση των 3 ονομάτων της Επιτροπής.
- Άκυρο πρωτόκολλο δεν αποθηκεύει αρχείο ή μεταδεδομένα και μπορεί να επανελεγχθεί αμέσως.
- Η εφαρμογή κινητού γράφει μέσω Firebase OTP και της `citizen-bridge`, όχι απευθείας στους πίνακες.

## Εγκατάσταση

1. Ακολουθήστε το `DEPLOYMENT_CHECKLIST.md`.
2. Συμπληρώστε στο `config.js` μόνο το URL και το anon/public key του νέου Supabase.
3. Δημοσιεύστε το repository με GitHub Pages από τον ριζικό φάκελο.

Οι οριστικές τεχνικές και λειτουργικές αποφάσεις βρίσκονται στο `docs/PROJECT_DECISIONS.md`.
Οι έλεγχοι που έχουν ήδη περάσει καταγράφονται στο `docs/LOCAL_VALIDATION.md`.
