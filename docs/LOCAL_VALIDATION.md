# Τοπική επικύρωση checkpoint

Ημερομηνία: 12 Αυγούστου 2026

## Έλεγχοι που πέρασαν

- Συντακτικός έλεγχος όλων των inline JavaScript blocks των δύο εφαρμογών και της σελίδας ACK.
- Συντακτικός έλεγχος των δύο Service Workers και JSON validation των δύο manifests.
- Bundling/syntax validation και των 6 Edge Functions:
  - `citizen-bridge`
  - `verify-pdf-signatures`
  - `admin-delete`
  - `send-order-email`
  - `manage-app-user`
  - `resolve-maps-link`
- PostgreSQL parsing και των 8 SQL αρχείων migrations/bootstrap/export.
- Πραγματική εκτέλεση των 3 migrations σε καθαρή προσωρινή PostgreSQL 17.
- Πραγματική εκτέλεση της αλυσίδας read-only export → νέα Auth UUID → import → clean-start verification σε δύο χωριστές προσωρινές βάσεις.
- Επιβεβαίωση ότι passwords/tokens και παλιοί μετρητές δεν περνούν στην εξαγωγή/εισαγωγή.
- Επιβεβαίωση ότι αιτήματα και εντολές ξεκινούν από `001` και επαναχρησιμοποιούν τον μικρότερο αριθμό που ελευθερώθηκε.
- Επιβεβαίωση ότι δεν επιτρέπεται παράκαμψη της αρίθμησης ή αλλαγή ήδη δοσμένου αριθμού.
- Επιβεβαίωση ότι η διαγραφή εντολής ελευθερώνει τον αριθμό και επιτρέπει νέα εντολή για το συνδεδεμένο αίτημα.
- Επιβεβαίωση ότι διπλό/ελλιπές σύνολο ονομάτων πρωτοκόλλου απορρίπτεται χωρίς εγγραφή πρωτοκόλλου.
- Επιβεβαίωση ότι 3 διαφορετικά ονόματα, με αλλαγή πεζών/κεφαλαίων και σειράς ονόματος–επωνύμου, γίνονται δεκτά.
- Επιβεβαίωση ότι η παραλαβή δεν μπορεί να δηλωθεί με απευθείας client update και ότι η παραληφθείσα εντολή παγώνει.
- HTTP smoke test με απόκριση `200` για όλες τις στατικές διαδρομές, manifests, Service Workers και icons.
- Έλεγχος ότι κανένα deployable αρχείο δεν περιέχει το παλιό Supabase project ref, παλιό repository URL, secret/service key ή παλιό cache/database key.
- Επιβεβαίωση ότι το παλιό τοπικό clone παραμένει καθαρό και το push remote του είναι απενεργοποιημένο.

## Τι απαιτεί ακόμη το νέο πραγματικό περιβάλλον

- Εκτέλεση των migrations στο νέο Supabase project.
- Δημιουργία των νέων Auth users και εισαγωγή των πραγματικών δεδομένων αναφοράς.
- Deploy των Edge Functions και ρύθμιση Resend/Firebase secrets.
- Συμπλήρωση του νέου Project URL και publishable/anon key στο `config.js`.
- End-to-end έλεγχος με πραγματικό Firebase OTP, πραγματικό υπογεγραμμένο PDF και πραγματική δοκιμαστική αποστολή email.

Κανένα από τα παραπάνω εξωτερικά βήματα δεν εκτελέστηκε στο παλιό ή σε νέο online περιβάλλον κατά τη δημιουργία αυτού του checkpoint.
